- `ai-order.png`: ảnh chụp riêng phần trợ lý trên production ngày 02/11/2026.

  ảnh sinh bằng AI để giả đầu ra ứng dụng; không có token, mật khẩu hoặc email khách
  trong phần ảnh được sử dụng.
