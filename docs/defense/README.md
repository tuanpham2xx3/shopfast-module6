# Bộ trình bày bảo vệ

- Mở [deck HTML](index.html) bằng Chrome/Edge: phím trái/phải chuyển trang, N hiện ghi chú; không cần server hoặc kết nối mạng để xem nội dung.
- [PDF 10 trang](shopfast-defense.pdf) dùng khi máy trình chiếu không hỗ trợ HTML; ghi chú nằm trong HTML và [kịch bản diễn tập](../18-defense-walkthrough.md).
- Tái xuất và kiểm khung: từ repository root chạy `node tools/scripts/render-defense.mjs`. Cần dependencies trong tools và Chromium Playwright đã cài. Ảnh từng slide và validation report ở ignored `harness/reports/defense/`.

Đã kiểm 10 slide bằng trình duyệt ở1280×720, không có nội dung vượt khung; xem trực quan từng slide. Bản PDF xuất bằng Chromium. Đây là HTML/PDF, chưa phải PowerPoint hoặc bản đã diễn tập đủ10phút. Các số đo trên slide giữ SHA lịch sử, không được hiểu là kết quả của mọi release mới.
