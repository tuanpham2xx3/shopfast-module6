# Evidence

Thư mục dành cho kết quả thực tế; hiện chưa có test hoặc nghiệm thu sản phẩm nào được chạy.

Lưu theo `M<so>/<case-id>-<ngay>/`: biên bản, lệnh chạy, báo cáo test/coverage/load và ảnh nếu cần. Log phải che secret và dữ liệu cá nhân. Không đưa file .env hoặc API key vào evidence.

Trạng thái khởi tạo của toàn bộ case trong `../08-acceptance.md`: NOT_RUN. Các yêu cầu hạ tầng: DEFERRED theo chỉ dẫn người dùng.
