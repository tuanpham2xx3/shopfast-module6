## Runtime contract

- `JobsModule` exports `JobsRuntime`; central API imports module. Central migration registry includes `Jobs1780000500000`.
- Worker uses BullMQ `shopfast-jobs` as primary dispatch and PostgreSQL execution records as fenced lease/idempotency authority. Outbox polling is 250 ms. Redis outage leaves durable backlog; no claim that live Redis acceptance passed.
- Worker exports `registerOutboxSubscriber(callback(event, source))`. Root registers a subscriber which filters `catalog.invalidate`, performs runtime cache invalidation, and throws when unavailable. Without any subscriber, catalog invalidation remains failed/pending rather than being silently acknowledged.
- Ticket classification invokes `AiService(new TicketsService(source, schema)).classify(ticketId, classificationVersion)` via a leased job.
- Failed BullMQ domain events are reconciled into `failed_jobs`; reconciliation retries archive writes after DB recovery. Business job terminal failures archive transactionally with their execution state. Retained BullMQ failures remain visible. Admin retry keeps business key/history and records actor audit.

## Adapters and limitations

- Invoice v1 is a real PDF generated by PDFKit and stored privately in PostgreSQL `bytea` with SHA-256 checksum and unique order/version semantics. A local durable storage adapter, not a cloud storage claim. `PDF_FONT_PATH` can select a Unicode font; native Windows Arial/Linux DejaVuSans are used when present.
- Invoice metadata and downloads require verified customer bearer authentication and server-side ownership. The URL additionally carries a five-minute HMAC bound to order/user/expiry, never a JWT. Downloads recheck PAID and exclude cancelled/expired orders. UI must fetch an authenticated blob.
- Configure `INVOICE_SIGNING_SECRET` (at least 32 characters); development can reuse `ACCESS_TOKEN_SECRET`.
- `EMAIL_PROVIDER_URL` and `EMAIL_PROVIDER_TOKEN` select the HTTPS email adapter. It sends `Idempotency-Key` and uses a ten-second timeout. Provider must actually honor this contract; live acceptance remains NOT_RUN. No email credentials are returned to the browser.
- Without email provider configuration, non-production uses the explicit `development-fake` adapter which records only fake delivery keys. Production refuses this adapter.
- Partner integration is the specified version-ordered development mock; production refuses it. No real partner provider acceptance claimed.
- `GET /admin/queues` reports BullMQ counts only when Redis can be queried, otherwise unavailable/null with freshness timestamp; DB execution counts are separately labeled. `queueSnapshot()` can be used by central admin health.
- Revenue CSV is admin-only at `/admin/reports/revenue/:date`; emails reference that protected route. Formula is DELIVERED orders whose delivery history timestamp is within Bangkok business date.
